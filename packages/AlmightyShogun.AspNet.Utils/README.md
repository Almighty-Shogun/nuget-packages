# 🚀 `AlmightyShogun.AspNet.Utils`

A C# library that adds standardized HTTP error responses, localized messages, exception handling, and request helpers to ASP.NET Core.

## 📃 Prerequisites
- **[.NET](https://dotnet.microsoft.com/)**: >= 10

## 📦 Building

```sh
dotnet build packages/AlmightyShogun.AspNet.Utils/AlmightyShogun.AspNet.Utils.csproj
```
