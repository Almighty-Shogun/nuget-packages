# 🚀 `AlmightyShogun.AspNet.Auth.Credentials`

A C# library that adds username or email password authentication, refresh sessions, and password reset helpers to ASP.NET Core APIs.

## 📃 Prerequisites

- **[.NET](https://dotnet.microsoft.com/)**: >= 10

## 📦 Building

```sh
dotnet build packages/AlmightyShogun.AspNet.Auth.Credentials/AlmightyShogun.AspNet.Auth.Credentials.csproj
```
