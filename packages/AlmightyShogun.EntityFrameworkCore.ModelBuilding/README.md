# 🚀 `AlmightyShogun.EntityFrameworkCore.ModelBuilding`

A C# library that adds Entity Framework Core model-building helpers for relationships, indexes, enum storage, and eager loading.

## 📃 Prerequisites
- **[.NET](https://dotnet.microsoft.com/)**: >= 10

## 📦 Building

```sh
dotnet build packages/AlmightyShogun.EntityFrameworkCore.ModelBuilding/AlmightyShogun.EntityFrameworkCore.ModelBuilding.csproj
```
