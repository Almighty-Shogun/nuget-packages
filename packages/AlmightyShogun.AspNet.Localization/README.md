# 🚀 `AlmightyShogun.AspNet.Localization`

A C# library that adds request language negotiation and localized messages to ASP.NET Core.

## 📃 Prerequisites
- **[.NET](https://dotnet.microsoft.com/)**: >= 10

## 📦 Building

```sh
dotnet build packages/AlmightyShogun.AspNet.Localization/AlmightyShogun.AspNet.Localization.csproj
```
